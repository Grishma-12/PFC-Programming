# C_Programming_Module

This directory contains practical C programming exercises for the PFC course.

## Structure

- `practical2/` - earlier exercises
- `Practical3/` - loops, date, operations
- `Practical4/` - mortgage, secure input, etc.
- `Practical6/` - student score operations (Sort, Search, Modular, Secure)

## Goal

Keep this document updated when adding new files or folders.

## How to use

1. Review exercise folder.
2. Compile and run with `gcc <file>.c -o <file>`.
3. Use comments in each C file to explain logic and steps.

## Add documentation policy

Every new practical should include a top comment block with:
- problem description
- input and output format
- sample usage
- date and author
